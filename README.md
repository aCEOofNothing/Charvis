# Charvis
Charvis is a little assistant system.

## Features
- Voice input
- Command execution (system + apps)
- Simple web UI
- Python-based core

## Installation
1. Python installieren
2. Neuste Realeseversion downloaden
3. Abhängigkeiten installieren
4. Zum Starten main.py ausführen
